# Stupid Log Documentation

Stupid Log is a single-user personal gaming archive built with Laravel, Inertia, React, TypeScript, Tailwind CSS, and a relational database.

## Source Of Truth

- `docs/specification.md` defines the V1 product rules and expected behavior.
- `docs/architecture.md` describes the app structure and implementation boundaries.
- `docs/data-model.md` documents tables, ownership rules, and relationships.
- `docs/versions/v1.0.0/plan.md` is the current mission board.

## Project Areas

- Backend: controllers, models, services, migrations, seeders, validation, provider integrations, and Inertia/API response contracts.
- Frontend: React/Inertia pages and components that consume documented backend props.
- Docs: kept current whenever backend logic, response shapes, data rules, or user-facing contracts change.

## Current Version

Current documented version: `v1.0.0`.
