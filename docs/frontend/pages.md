# Frontend Pages

## `Home`

Uses dashboard stats, recent games, and reference data for the add-game wizard.

## `Library`

Uses full library game cards and reference data. Search/filter behavior is currently client-side.

## `GameDetails`

Uses one library game card shape and a DLC list.

## `Stats`

Uses live stats.

## `Snapshots`

Uses snapshot runs and confirmed current year stats.

## `Setup`

Uses currency list and posts setup values.

## `Settings`

Uses user/settings, currencies, and provider list.
