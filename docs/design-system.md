# Design System

## Product Feel

Stupid Log should feel like a clean, playful game archive hub, not a generic CRUD admin panel.

The current UI uses:

- bold typography
- large visual game cards
- bright lime accent color
- black contrast surfaces
- rounded card and panel treatments
- lucide-react icons

## Current Visual Tokens

Observed accent colors:

- Lime: `#b7ff63`
- Black: `#000000`
- Blue: `#4f8cf7`
- Soft gray: `#d8ddda`
- Yellow: `#f4df4d`
- Red: `#ff3131`

## Frontend Change Rule

Codex should not invent major UI/UX direction. Backend-facing frontend edits may update prop handling, forms, or mechanical integration when required.

When layout, hierarchy, visual style, or component behavior is unclear, ask for frontend direction using the `TO_CHATGPT_FRONTEND_LEAD` handoff format from `AGENTS.md`.
